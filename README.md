# Mike Hamilton

### AI Technical Leader | Genomics & Healthcare | Model Evaluation & Applied Research

I build AI/ML and scientific software where the cost of being *plausibly right* is not good enough. My work spans multiple generations of machine learning—from SVMs, kernel methods, structured prediction, and statistical learning through computational biology, genomics, molecular diagnostics, production ML, and modern model evaluation.

I am currently a **Staff Data Scientist at MCG Health**. Across my career, the recurring pattern has been end-to-end technical ownership: understand the domain, define the real problem, design the analytical and system approach, build it, operationalize it, and determine whether it actually works.

> **Build AI — and build the evaluation, evidence, provenance, and engineering needed to hold AI accountable.**

## Selected Public Work

### [iDiffIR](https://github.com/bio-comp/idiffir)
**Differential intron retention from RNA-seq data.** Research software from my transcriptomics work, now modernized for Python 3.10–3.12 with current packaging, tests, CI-oriented quality gates, and improved CLI behavior.

### [HMMPY](https://github.com/bio-comp/hmmpy)
**Hidden Markov Models in Python.** A modernized implementation of core HMM algorithms including forward/backward inference, Viterbi decoding, Baum-Welch training, classification, visualization, notebooks, tests, and documentation.

### [TAPIS](https://github.com/bio-comp/tapis)
**Transcriptome Analysis Pipeline for Isoform Sequencing.** Historical research software for long-read transcriptomics: alignment/correction, transcript clustering, splice-isoform detection, and polyadenylation/alternative-polyadenylation analysis.
